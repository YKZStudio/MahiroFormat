## 新增功能

- PDF → DOCX：提取文字与表格，生成标准 Word 文档。
- 视频 → GIF 动图；WebP 动图 → GIF。
- XLSX/XLSM → 旧版 XLS。
- ZIP → PDF：合并压缩包中的图片，并防止 zip-slip（ZIP 路径穿越）。
- PPT/WPS → PNG/JPG：逐页转图并打包为 ZIP。
- PDF 拆分与密码解密。
- PDF → XLSX 质量门禁：扫描页置信度过低时返回明确双语错误，不再输出不可用工作簿。
