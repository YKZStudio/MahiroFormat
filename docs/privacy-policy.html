Mahiro Format Privacy Policy

Last updated: August 29, 2026

Mahiro Format is a desktop file converter maintained by YKZStudio and originally created by LaoFeng. This policy explains how the application handles data.

1. No developer account or telemetry

The application has no Mahiro Format account system, advertising SDK, analytics service, or developer-operated cloud conversion service. It does not automatically send files, settings, or logs to the developers.

2. Local file processing

  • Selected files are processed in local memory and application-controlled temporary directories.
  • Source files are not modified. You choose where completed results are saved.
  • Temporary uploads and results are removed by the local cleanup process. Abrupt termination may leave temporary data until the next cleanup or manual removal.

3. Optional network-dependent compatibility

Most conversions work offline. Some experimental QQ Music musicex variants may require a valid QQ Music web credential to request a conversion key from QQ Music. When that feature is used, the song identifier and credential are sent to QQ Music's service; the audio file is not uploaded to Mahiro Format or its developers. This optional path is hidden and rejected in Microsoft Store builds.

4. Local settings and logs

The application stores the interface language, preferred target for each source extension, last successful save directory, and a local debug log. Logs may contain filenames, engine paths, status messages, and errors, but are not intended to contain file contents or credentials. These records are not uploaded automatically.

5. Third-party components

Conversion components run locally, including FFmpeg, LibreOffice, Poppler, Tesseract, Sharp, qpdf, and document-processing engines. Each component is governed by its own license. The bundled document engine includes PyMuPDF under AGPL-3.0; source is available from the PyMuPDF repository.

6. User control

You can remove saved preferences and logs by deleting Mahiro Format's application-data directory. Uninstalling the application may not automatically remove user data or files that you deliberately saved elsewhere.

7. Contact and updates

For questions, open an issue in the current GitHub repository. Policy changes will be published on this page with a new update date.
