Mahiro Format 隐私政策

更新日期：2026-08-29

Mahiro Format 是由牢蜂（LaoFeng）原作、YKZStudio 升级维护的桌面文件转换工具。本政策说明应用如何处理数据。

1. 不提供开发者账号或遥测

应用没有 Mahiro Format 账号系统、广告 SDK、分析服务或由开发者运营的云端转换服务，不会自动向开发者发送文件、设置或日志。

2. 本地文件处理

  • 所选文件只在本机内存和应用控制的临时目录中处理。
  • 源文件不会被修改；转换完成后由你选择保存结果的位置。
  • 本地清理流程会删除临时上传和结果。应用异常退出时，临时数据可能保留到下次清理或由用户手动删除。

3. 可选的联网兼容功能

绝大多数转换可离线完成。部分实验性的 QQ 音乐 musicex 变体可能需要有效的 QQ 音乐网页登录凭据，向 QQ 音乐请求转换密钥。使用该功能时，会向 QQ 音乐服务发送歌曲标识和凭据；音频文件不会上传给 Mahiro Format 或其开发者。Microsoft Store 构建会隐藏并拒绝这一路径。

4. 本地设置与日志

应用会在本地保存界面语言、每种源扩展名的首选目标、最近一次成功保存的目录和调试日志。日志可能包含文件名、引擎路径、状态和错误，但不应包含文件正文或凭据；这些记录不会自动上传。

5. 第三方组件

FFmpeg、LibreOffice、Poppler、Tesseract、Sharp、qpdf 和文档处理引擎等组件均在本机运行，并分别遵循各自许可证。内置文档引擎包含采用 AGPL-3.0 的 PyMuPDF，源码见 PyMuPDF 官方仓库。

6. 用户控制

你可以删除 Mahiro Format 的应用数据目录来移除已保存的偏好和日志。卸载应用不一定会自动删除用户数据，也不会删除你主动保存到其他位置的转换结果。

7. 联系与更新

如有疑问，请在当前 GitHub 仓库提交 Issue（问题）。隐私政策变更会在本页面发布，并更新日期。
