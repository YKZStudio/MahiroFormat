# 0.7.2 修复与验收记录

2026-09-13：本版修复 0.7.1 独立验收确认的 Markdown 保存误改、Office 缓存替换失败、变形扫描图 OCR、英文漏译和包内 Agent 指引漂移。新增独立复核还发现并修复空缓存锁无限等待、200% 英文缩放下打赏入口遮字。Windows 10/11 x64 完整版已通过本地验收后进入源码同步和 APPX 打包流程；商店安装、认证及公开发布属于独立状态。

## 实际改动

- Markdown 保存按 CommonMark/GFM 和 HTML 语法中的原文位置只改附件目的地址。正文、代码、标题、转义、BOM 和 CRLF 保持原样；缺真实附件仍拒绝，旧文档和旧附件不受影响。
- Office 缓存发布前保留已有目录；发布失败恢复旧路径，回滚失败保留最后副本供下次恢复验证。跨 Worker/进程锁保护复制、验证、发布和回收。空锁及竞争重试均遵守期限；释放先移走本 token 活动锁名，再清理文件。未知所有者的锁保留并给出诊断，不抢占活进程。
- 非等比缩放的可见内嵌扫描图按原像素比例分区 OCR，按位置合并原生文字。裁剪、遮挡、透明或隐藏内容回退页面渲染；单图 50MP、单页原图合计 100MP。局部文字质量检查避免清晰英文掩盖中文乱码，中文换行不再并段。
- 英文用途及音频说明补齐翻译；窄屏支持入口进入文档流，不遮盖流程。浅色、深色、随系统及重启持久化保留。包内 Agent 指引与当前源码一致。
- Windows CI 使用新的唯一 1.0.1 结构引擎资产，与完整文件锁匹配，不替换旧资产或放宽校验。Markdown 解析器及传递依赖保留原许可证，主线与隔离 Win7 锁同步到 0.7.2。

## 验收证据与范围

完整 npm 测试的前置结构测试与主测试、APPX 校验器测试、生产依赖审计均通过；具体计数以随交付的本轮验收报告和日志为准。跳过项单列，不计为通过。

真实程序检查包含 Markdown→Word 的标题、表格、嵌套列表、代码和 3 个可编辑 Office Math 公式；旋转 PDF 的完整 HORIZONTALTEXT；混合扫描、倾斜、多方向、多页 TIFF；扫描表格 4×4 格位及 12 个空白格；字幕时间轴/Unicode；Word、Excel、PPT、Markdown→PDF 的实际渲染。原失败采购单经新 EXE 转 DOCX/Markdown/TXT 后保留标题、474.00、712.00、1186.00、电话和全部七行原生英文，Word 可编辑并正常按段落排列。

独立故障测试涵盖 Markdown 原字节、实际 HTTP 附件、缺附件旧文件保护、缓存发布/回滚双失败、空锁期限、Worker 中断和并发。包内 Worker 冷缓存执行 51 文件哈希与真实 CSV→PDF 内容验证，暖缓存复用收据。真实 Electron 验证三种主题、持久化/重启、英中文案、12 个缩放组合、12 组对比度及窄屏支持面板交互；测试使用隔离用户数据。

## 保留的边界

- 扫描 PDF 的复杂版式可能重排；少数标点仍需对照原稿复核，不能宣称任意文件 1:1 还原。单文件 CLI 上传不会自动上传相邻 Markdown 图片，嵌入图片可用，缺失相邻资源必须显示提示。
- LibreOffice 在过深的自定义 TEMP/缓存路径下仍可能失败。普通 Windows 临时路径和当前本地交付路径分别验收，人工构造的深目录失败不计为通过。
- 缓存两次改名支持中断后恢复，不是物理断电或磁盘损坏事务保证；未知空锁限时诊断，不静默删除未知目录。
- 本轮不宣称 Win7 安装包、macOS DMG 或真实 Win7/Mac 设备验收通过。CI、源码同步、桌面入口、APPX 容器、Store 安装和商店发布分别记录。
- 当前能力表不支持 AV3A 或平台加密音频。最终本地 EXE 的能力查询及拒绝探针确认这些扩展名没有转换目标、不会生成伪输出；它们不是实际音频解码成功测试。已更正历史文档中遗留的 AV3A 发布检查要求和引擎宣传，未新增或恢复已移除的音频路由。

历史状态见 [0.7.1 记录](REPAIR-0.7.1.md)；其旧测试计数与旧包哈希不能代替 0.7.2。
