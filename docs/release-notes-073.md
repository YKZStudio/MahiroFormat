# FlyingMouse Format 0.7.3

作者：牢蜂（LaoFeng）。仅供个人免费使用，禁止商业售卖、转卖及套壳。

本版本改善启动、配置保存与转换的稳定性：

- 修复本地界面受代理影响的白屏；加载失败或渲染崩溃时提供原生提示和重试。
- 改善 LibreOffice 在配置目录不可用时的启动行为，并终止超时的本次子进程。
- 修复设置跨卷保存失败时可能损坏已有配置的问题。
- 修复转换期间重新选择文件造成的结果混入，以及慢识别覆盖新选择的问题。
- 同名 Word 转 Markdown 的图片目录相互隔离，避免覆盖附件。
- 修复 PDF 分组拆分回退、图片 PDF/ZIP 写入错误处理及非 NTFS 目标保存。
- 收紧本地转换接口来源检查，保留原有鼠鼠界面、主题和语言偏好。

Windows 10/11 x64 候选安装器与 APPX 已构建验证，本机程序已更新。公开发布与 Microsoft Store 上架状态以渠道实际显示为准。

仍有验证边界：极深的自定义 LibreOffice 引擎资源路径可能启动失败；原反馈机器、正常 Store 容器、实体 FAT/exFAT、Win7 及 macOS 尚未完成本版复测。完整证据和测试范围见 [修复与验收记录](REPAIR-0.7.3.md)。
