你可能想知道

转换文件需要联网吗？

常规文件转换在本机进行，内置引擎齐全时可离线使用，不会把文件上传到云端转换服务。软件与引擎下载需要联网；部分实验性音乐容器的兼容流程可能需要平台凭据与网络请求。

为什么系统会提示安装风险？

当前 Windows 安装包未签名，macOS 安装包未签名、未公证，系统可能提示或拦截。请从本项目发行页获取安装包，核对文件名和 SHA-256；有关安装与平台限制，请阅读发行说明。

Windows 7 和 Mac 版本有什么区别？

Windows 10/11 x64 是主线版本。Win7 SP1 x64 使用独立旧版运行环境，不含标准 Windows 文档引擎；Mac 提供 Apple Silicon 与 Intel 两种安装包，同样不含该文档引擎。请查看发行说明中的系统要求与真机验收状态。
